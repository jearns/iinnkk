## 新增

- 实验室新增「字迹方舟」独立页（handwriting254.html）及「见字识人」（ink-person254.html）。目前公开访问，字迹留在本机 IndexedDB，不依赖登录或 Supabase，不新增云端数据流量。
- 临帖、填字、随手创作、搜索输入手写、共书及实景分别累计字数、笔画和书写时长。确认字按实计数，未识字稿明确标为估算。重复保存、改色、旧作汇入通过笔迹指纹去重；删除字样不抹除累计练习历史。
- 字迹集中选择、搜索、标注、识字整理、字集、回收恢复及 JSON 备份。旧作只读本机矢量笔迹，不下载书页图片。

- 字样或已保存填字盘可生成毫米制立体印面，支持凸起/凹刻、镜像、平台尺寸检查，按需加载 Three.js 交互预览，导出闭合实体 STL 和标准 OPC 3MF。可下载本机 Blender 助手，连接后生成、渲染、编辑真正 .blend 项目；无助手时导出含模型/脚本的 Blender 项目包。网页不内嵌完整 Blender，也不自动启动打印机。
- 见字识人依据笔画数、书写节奏、转折、占纸等可观察量生成积极的艺术画像。明确以娱乐为主，不推断真实人格、健康、能力或命运。

- 全站 text/search/textarea 自动打开轻量手写输入，保留键盘切换。密码、邮箱、地址、数字与只读输入不接管。
- 复用原书写引擎图标与参数控件；填字工具不加载预览/下载面板，作品入口进入全站作品页。底部依次为「确认、格盘、提示、更多」，透明小按钮。提示无需先写一笔。
- 所有关卡均有横纵交叉，去掉不参与交叉的独立词。连续填字、全局笔径、英文逐字母和整词识别保留。
- 保留本地笔迹匹配，并增加私有确认字学习；疑难输入按需载入 PaddleOCR PP-OCRv5 mobile ONNX + ONNX Runtime WASM。模型低置信度只提供候选，不擅自确认。连笔识别有所改善，但无法保证任意行草正确，仍提供候选、提示与手动选择。

## 负载、隐私与后续登录

- 字体、3D 及 OCR 模型均延迟加载，不进入首页/填字启动核心离线资源。书写采集增量合并，不逐笔扫描全部作品。无新增 Supabase 请求、轮询或全书预取。
- 用户笔迹、标准字标注、自定义字集和作品名不进入在线翻译。五种界面语言补齐公开 UI。
- 账户迁移方案见 ACCOUNT-254.md。已安排 2026-10-28 起检查实际配额恢复；仅验证恢复后执行账户隔离与迁移，不按日期自动开启登录。游客数据须备份和明确认领后绑定账户，未来使用 owner RLS 与幂等增量同步。

## 主要开源依据

- PaddlePaddle/PaddleOCR 及官方 PP-OCRv5_mobile_rec ONNX 发布（Apache-2.0）；ONNX Runtime Web（MIT）。许可证、模型来源及 SHA 在 hand254/ocr-license254.txt 和 vendor254。
- opentype.js（MIT）、Three.js（MIT）、fflate（MIT）。真实字体轮廓/3MF 由本地生成，不借用商业字体字形。
- Blender 官方 Python API 与后台渲染；Apple Device Management Font payload（com.apple.font）。字体安装不承诺操作系统不支持的全局替换。
- 笔迹人格推断缺乏可靠验证依据，因此仅提供可观察的笔迹风格及正向娱乐反馈。
