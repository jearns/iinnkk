## 目录与构建约定（316）

- `app/`：网站页面、功能模块、源码、测试与网站资源。手动上传音乐请放在 **`app/music/`**；碑帖资源放在 `app/timeline/`。
- `docs/`：旧版设计、发布记录和参考文档。
- `tools/`：根目录固定构建入口和目录检查。
- 根目录的 `index.html`、`404.html`、`sw.js` 仅负责入口和旧网址兼容；不再创建带版本号的根目录页面或功能目录。

在根目录执行 `npm run build:current`、`npm run check:release`。构建仅保留当前与上一版书写运行文件，自动删除没有生产引用的散列构建文件。功能模块改动原文件；历史实现通过 Git 提交记录追溯，不复制整套页面为新版本。发布前必须通过 `npm run check:structure`，防止根目录重新堆积。应用页面移动不改变同源本机作品存储，不清空作品、纸张或音乐文件。

配乐的有效衍生音源统一存放于 `app/music/library/`，原始上传文件继续留在 `app/music/`。不再创建 `video-music数字` 目录。现有 `revision` 与 `release` 文件中仍有当前书写引擎实际依赖的功能；更新这些功能时修改现有源文件，新增功能使用稳定名称，不继续复制新编号目录。目录检查会阻止新增编号副本，并核对保留页面所引用的脚本、样式是否存在。
