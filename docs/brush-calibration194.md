# 194：五种经典书风调校

参考用户按顺序上传的泰山刻石、熹平石经、多宝塔碑、兰亭序、古诗四帖局部。实现采用图像观察与明确的笔触参数、几何规则调校；五张图没有被用来训练新的神经网络。

| 预设 | 图像观察 | 引擎实现 |
| --- | --- | --- |
| 李斯·篆书 | 骨架匀称修长，线条圆转；碑石破损不等同于枯笔 | 匀宽中锋、二次曲线圆转、圆头圆尾，取消速度削细和尖尾 |
| 蔡邕·隶书 | 横向舒展，主横头尾厚、腰身轻；次横平收 | 饱满起笔，长横末段波磔、上挑切面；短横保留平收 |
| 颜真卿·楷书 | 方正骨力，横竖有粗细差，捺脚重按后拖出 | 横轻竖重，折处增压，横尾顿收，捺脚增厚后楔形收锋 |
| 王羲之·行书 | 露锋与藏锋交替，提按细致，行笔映带 | 速度提按、轻灵尖锋、平滑使转，保留实际牵丝轨迹 |
| 张旭·草书 | 粗细悬殊，长笔浓淡与干湿变化，飞白仍有骨力 | 大幅速度提按、墨色随行程变化、干湿纹理和边缘纤维 |

自定义综合书风的0、25、50、75、100分别对应五个通道；中间数值连续插值。五通道权重和为1。已有作品保留原始采样点、每笔笔径与页面坐标；不对手写字作自动字体替换，也不凭空添加笔划或跨抬笔连字。结体长宽、欹侧和连字通过预设说明引导，仍由手写轨迹决定。

透明纸张的封面、缩略图在独立画布上衬白再编码JPEG。旧版黑图可从其原始笔迹重新生成，保留作品ID、页ID和云端关联，不恢复或覆盖当前书写环境。PNG导出的透明纸张行为继续保留。

公开殿堂只读取published=true且未回收的记录，作品先展示，热度异步更新。排行榜、评论、关注扩展尚未加载时不能阻断作品列表。布局按时间分组、自适应窗口，关闭按钮拥有独立列。

验证：五通道融合、篆书匀宽、颜体横竖比例、隶书头尾、草书墨色/纹理、竖钩连续与收锋、白底缩略图修复及ID保留、生成运行时书风菜单与启动、殿堂在扩展失败时仍显示作品、导出、离线和存储检查。另以匿名REST请求验证26幅公开作品可读取，并核对26幅作品的图片文件仍存在。
