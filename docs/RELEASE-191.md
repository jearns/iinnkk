191：竖钩接缝、临帖透明度与手机书写

墨迹沿原始采样路径连续前进；缓和收锋处半径变化，使用平滑过渡，加密尖锋接触，减少竖弯钩左出锋的突然收窄与圆头接缝。
原帖裁切和悬浮共用透明度；拖动即时刷新书写与预览，拖动期间不重建当前控件。
临帖默认综合书风75、纸张300%、笔径150、黑墨、透明纸色，配色固定；两处缩放锁共用状态，锁定后禁用参数面板缩放控制。右下数值点击打开纸笔面板。
下载面板私藏和导出并排，临帖导出、归入专辑、使用设置固定三列；离线就绪只在首页显示。手机抬笔后较早走纸并保留更多续写空间。
