# Release 205

204 regressions were rechecked before the changes. Writer Works retains its drawing document and shares its store; pending saves finish before mutations and deleting the active record clears editor identity. Initial caching remains core code plus Lanting, followed by five images per live chapter in the background.

## Brush: bounded interpretations of the six classical metaphors

The 194 pressure/speed law, stored trajectory and hook endpoints remain the baseline. These are visual control models, not a full fluid or fiber simulation.

- 锥画沙: coherent paper-distance contact variation and stronger filtering of tiny heading changes; real folds remain distinct.
- 印印泥: solid, single-contour ink body, no artificial shadow, gray overlay or paired outline.
- 折钗股: running/cursive turns retain some preceding contact width to avoid an abrupt thin corner.
- 屋漏痕: vertical contact responds slightly to recorded dwell time, without random displacement of the centerline.
- 壁坼路: actual hand-drawn connections and character placement are retained; no generated grid alignment or random character offsets.
- 万岁枯藤: sparse directional fiber openings only in the final short, fast, lifted cursive tail; full-stroke dry masking and edge rails are excluded.

## Shared waiting surface

Seven greetings form a CSS 3D rotating sphere with geographic longitude/latitude language regions. Caption: “让世界留下你的手笔！” The old loading SVG and slogans are removed from the writer source. Home startup, engine/reference entry, catalogue, works, hall and asynchronous user actions reuse loading205. Concurrent waits use independent tokens and close the top-layer dialog only when all complete. Background warming does not invoke it. Reduced-motion users get a static globe.

## Catalogue and passport

Era and script values are canonicalized for both options and matching. Author choices omit attribution prefixes, unknown names and literary/engraving roles, merge duplicate actual names and sort by pinyin. Original attribution text stays in the catalogue descriptions.

Passport gates use the exact `masterpieces10` list. Three Rarities count as one group while recognizing the saved source identity of its individual pieces. Ten equal-width pairs show originals alongside saved user ink. Saved album pages can be selected; the original switches with the chosen page. Export uses archived artwork when available rather than the 240px preview. The share button generates one 1200px-wide PNG containing all ten gates, invokes native file sharing when supported, and otherwise downloads it. Unavailable images retain an explicit placeholder rather than deleting a gate.

Validation: 53 targeted checks, including generated writer initialization with stalled reads, save/delete concurrency, group completion, author normalization, overlapping loader lifetimes, paired page selection and a real canvas 1200×6080 PNG export. Canvas comparison inspected for dense horizontal joins, sweeping strokes and running turns. Native iOS/Harmony touch response and system share sheets have not been verified.

Incoming catalogue upload commits are retained. Alternate titles match an exact institutional object URL when it identifies a specific object, preventing unrelated poems from being substituted.

The common modal normalizer excludes waiting205, so it cannot add an unrelated settings heading to the globe. Collapsing a wait surface is labelled accurately and does not claim to navigate home.
