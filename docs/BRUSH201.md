# Release 203: restore the 194 brush baseline

The user rejected the 201/202 renderer. `brush.js` is restored from commit `2203c0751675e4b8cfaebd3aa377dba8005ffab7` (194). The original radius law, state, ribbon renderer, end recognition and seal/clerical behaviour are retained. Only small local Yan jitter smoothing and direction-width filtering are added. Running/cursive/regular channels use solid original ink without texture or whole-stroke gray changes. Previously requested preset values remain Wang 75/400 and Zhang 90/600. Perfect-Freehand and the 201/202 adapter are excluded from runtime sources; no second renderer is selected by old stored contour tags.

Works use one standalone versioned route from home, writer, and hall. Both works and hall load 10 metadata cards at a time; only the explicit More button expands the next group. Works use two staggered columns and restore batch selection, trash/restore, and cloud publish/private operations through existing owner-scoped services. No schema changes or direct permanent deletion are introduced.

Passport shows all Top20 gates in ranking order before loading practice records. Saved valid private/public originals stamp a gate; publication is not required. Local/cloud identities deduplicate records. Character counts are estimates from available original body strokes / 7. Image-only cloud records cannot provide verified character counts. Virtual ink-gold uses the existing RMB auction sample mean divided by available Top20 transcript mean character count; this is labelled as a reference formula, not a claim that museum originals have auction prices or that user works earn cash.
