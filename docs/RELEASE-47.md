# 第47版交付与部署说明

## 已实现

- 首页模板名称在图片下方；单字、写信、临帖快捷预设。
- 3:4 / 400% / 笔径18 / 竖线 / 描金云龙 / 线条优化默认；正文18、落款12快速定位。
- 回宫格、参考图片尺寸匹配、右上起笔的墨迹投影辅助定位；允许手动校正行列。投影分割不是文字OCR，复杂原帖仍需手动定位。
- 行尾不再根据短暂停笔跨列，四向透明按钮按字格移动；双击换行保留。
- 所有设置可选快捷图标、顶部/底部显示及排序，跨刷新保留。
- 服务端 D1 用户、角色、七天试用、设置、统计、作品、点赞、点评、临摹关联、模板和CMS；图片/可编辑笔迹存R2。
- 第一个经服务端验证身份的用户原子领取“书仙”；并发首次登录只产生一个创始人。书仙可升级/降级其他用户，不能降级或替换创始人。
- 书仙在网页编辑普通文本、字号、颜色、宽高、同容器模块顺序、隐藏/恢复；保存后访客可见。画布内的艺术字、绘制算法和功能逻辑不属于文字编辑器范围。
- 公开作品可点赞、点评、分享、临摹；带二维码版本使用该公开作品链接。私密作品不生成公开二维码。
- 位置由浏览器授权后取得，仅用于10公里查询，不保存用户轨迹。先用管理员维护的有来源史实，后查Wikidata有建立年份的附近地点；无结果不编造。
- 字数为笔画空间分组估算；统计只计算实际落笔与短间隔，不计浏览和长时间等待。

## 尚需网站所有者配置的外部服务

五个平台没有统一的免配置一键登录，当前未提供这些应用凭据。代码包含微信网页授权、通用OIDC流程（Google / Apple / 华为及经批准的小红书身份服务）；未配置的入口明确显示未启用，不是假登录。当前Sites站点可使用平台的ChatGPT登录。

- 微信：网站应用审核、回调域名；服务端设置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`。
- Google：OAuth客户端与回调地址；官方说明 https://developers.google.com/identity/openid-connect/openid-connect
- Apple：Services ID、站点验证和有效client secret JWT；官方说明 https://developer.apple.com/documentation/signinwithapplerestapi
- 华为：Account Kit网页应用与对应区域OIDC信息，需开发者控制台授权。
- 小红书：须获得适用的官方登录/身份接入许可；不把商家接口或抓取cookie当作普通用户登录。未取得许可前保持关闭。

OIDC配置只存在服务端环境变量 `OIDC_PROVIDERS`，不要提交Git：
```
{"google":{"clientId":"...","clientSecret":"...","issuer":"https://accounts.google.com","discovery":"https://accounts.google.com/.well-known/openid-configuration"}}
```
各平台回调固定为 `https://你的域名/api/auth/平台名/callback`。Apple使用form_post，服务端校验state、nonce、签名、issuer、audience和有效期；所有其他OIDC使用PKCE。小红书与华为必须采用获准的发现文档地址，不在代码里虚构端点。

## 根目录静态版与在线版

`index.html`继续是真正主页；根目录静态托管可以使用本机书写、模板和本机作品。账号、点赞、CMS等在线功能需要配套服务，不能仅上传HTML就拥有云数据库。

- `npm ci`安装依赖；`npm run build`生成 `dist/client` 静态文件和 `dist/server/index.js` Workers后端。
- Cloudflare自行托管：创建D1数据库和R2桶，在 `wrangler.jsonc` 填入真实数据库ID；执行数据库迁移；配置登录环境变量后部署。不要在普通Cloudflare部署上启用 `SITES_AUTH`，它只用于可信Sites调度器。
- GitHub Pages只支持静态模式，不提供在线账号、作品互动和管理API。Cloudflare Workers才运行配套服务；网络可达性不能保证所有大陆运营商一致。
- 首次启用账号时请创始人先登录。按需求，首个验证身份的账户会获得网站管理权限。
- 已有用户作品仍在原浏览器中；不清除浏览器数据、不迁移IndexedDB。云同步只在登录后发生，旧作品可从“同步本机作品到账号”选择上传。
- 更新时先备份；服务端、静态文件和迁移应作为同一版本发布。下载页使用校验清单准备完整ZIP。
