## 见字识人与字迹方舟

- 修复选字丢失：方舟把所选字样 ID 保存为本机选字快照，结果页只从这一快照读取，显示、证据统计与文字解读使用同一组笔迹。选择超过九份时，按九字一卷翻看；字样失效会提示重新选择，不会偷偷换成别的字。
- 结果采用竖幅九宫排版，三行三列；不足九份保留空位。保存直接使用原站 export-studio182 下载面板及 copy-download218 合成器，包含原有设置、框架、二维码、网站名称和落版。组件在点击保存后加载。
- 字体弹窗限制长字样预览高度，并固定生成/导出操作行；八十份字样时操作按钮仍可见。按钮明确命名为「生成字体」。
- 新增本机照片文字浮雕：上传大头照、选择正向词，用自己已写字样组成照片明暗轮廓。缺字明确列出，可用手笔弹窗补写；未写过的字不会伪造成个人笔迹。照片只用于艺术形象，不用于人格分析。
- 可缩放/移动照片、调整文字密度与三色，保存图片、调用系统相纸打印、预览文字浮雕并导出 STL/3MF/Blender 项目。左下阴刻地点章、右上阳刻干支节气长方章均在纸边线以内。
- 3D 预览分别设置格盘、字迹、印章颜色。3MF 记录三种基础材料和逐面分区；STL 格式只保留形体。拓竹等设备需要在切片软件中匹配材料/尺寸后打印，不会擅自启动打印机。本机 Blender 助手也保留三色分区，并继续验证输入网格与颜色数据。
