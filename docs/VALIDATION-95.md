# 第95版验证记录

基于第94版主线 `421ffa3679eeab29e173d8e6214eb60f8f532209`。

- 网页标签名只有 HTML 中的「今日亲笔」，清理所有旧脚本 `document.title` 赋值；离线缓存升级到95。
- 历史入口统一为「历史上的真迹」。头像使用 flex 居中、清除字距和内边距。
- 注册确认及登录后的个人资料沿用93版流程；增加可选性别、词牌昵称建议与换一个按钮，保留手动昵称。性别仅存于账号 metadata，不放到公开作者资料；仅超级管理员后台可读。密码仍只保留在当前页内存。
- 云端作品增加多选、全选、批量发布、私藏、删除和分类，以及新建分类。每次数据库批量变更同时限制选中 ID 与当前 owner，检查实际返回数量；删除要确认并清理当前用户的云端图片，本机原笔迹不受影响。
- 修复选字删除可达性：删除叉号限制在画布可点击范围内，选择层提高层级，工具条另有「删除选字」；两种删除都通过真实浏览器验证，均可撤销。
- 右上与预览下下载名称改为保存；预览步骤行居中。世界文化遗产文摘来源显示「国家·地点」，去掉冗余介绍前缀。
- 左上默认作品、录屏、选字、文摘、扩展，笔字标志始终最左。窄屏左区横滑查看，右区保留固定操作。顶部和底部图标按住450毫秒拖动，顺序保存在本机；顶部两组可互移，底部在底部内排序。标志不参与拖动。Alt+左右方向键也能排序。
- 100组配色：保留94版50组，新增50组文化色彩灵感，覆盖建筑、壁画、雕刻、园林、自然景观与非遗。每组有文雅名称、地点、描述和官方参考链接；色值是设计解释，不宣称照片实测值。随机仍优先作者国别/朝代，说明继续放装裱右下留白。
- 用户后台与通知已安装到实际 Supabase 项目；新表 RLS、注册触发器和 Realtime publication 检查通过。原书仙管理员保留。通知工作边界详见 [后台说明](ADMIN-95.md)。
